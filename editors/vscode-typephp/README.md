# TypePHP VS Code Extension

Extension hỗ trợ syntax highlighting và language configuration (comment, auto-closing brackets/quotes, indentation) cho các file `.tphp`.

## Cài đặt cục bộ (Symlink)

```bash
ln -s /home/long/Dev/typephp/editors/vscode-typephp ~/.vscode/extensions/typephp-language
```

Sau đó mở lại VS Code (hoặc `Developer: Reload Window`) và mở bất kỳ file `.tphp` nào.
